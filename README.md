## 🌟 Welcome to My Project!

Welcome to the Cafe Management System, a Python-based project developed by Mudit Sharma as part of a Semester 1 academic assignment. This project is designed to manage the basic operations of a cafe through a simple and user-friendly command-line interface.

The main purpose of this project is to make cafe management easier and more organised by providing features such as viewing food menus, placing customer orders, calculating bills automatically, maintaining order records, and tracking total sales.

Unlike graphical applications, this system works directly in the Python terminal. It provides a simple way to understand how programming concepts can be applied to real-world situations.

## 🎯 Project Objectives

- To develop a basic cafe management application using Python.
- To simplify the process of taking customer orders.
- To calculate bills automatically and accurately.
- To maintain records of completed orders.
- To understand the practical implementation of Python programming concepts.

## ✨ Features

1. **View Food Menu:** Displays available food and beverages with their prices.
2. **Place an Order:** Allows users to select multiple food items and enter their quantities.
3. **Automatic Bill Generation:** Calculates item-wise amounts and the final bill.
4. **Order Records:** Saves completed orders in a text file.
5. **Total Sales:** Displays the total sales generated during the current program session.
6. **Error Handling:** Handles invalid inputs and incorrect menu selections.
7. **Simple Navigation:** Provides an easy menu-based interface.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure Python 3 is installed.
4. Open the VS Code terminal.
5. Execute the following command:

```bash
python cafe.py
```

6. Select an option from the displayed menu.
7. Follow the instructions to place orders and generate bills.
